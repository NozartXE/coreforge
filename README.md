CoreForge is a GitHub-compatible git forge in a single Node process: git smart HTTP (clone, fetch, push, shallow clones over protocol v0 and v2), the REST v3 core resources (repos, issues, labels, pull requests, contents, commits, refs, branches), a GraphQL v4 endpoint, and an MCP endpoint — all served from one in-memory store with no dependencies beyond the Node standard library.

## Run it

```sh
node --experimental-strip-types main.ts
```
